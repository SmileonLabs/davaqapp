DAVAQ

DavaQ 개인정보처리방침

운영자: SmileOn Labs · 시행일: 2026년 10월 15일

DavaQ(다바꿔)는 만 13세 이상을 대상으로 TCG 카드 검색·시세 조회, 실물 카드 교환·나눔, 피드·메신저와 음성·영상통화를 제공합니다. 이 방침은 DavaQ의 iPhone·Android 앱과 PC 웹·PWA에서 처리하는 개인정보에 적용됩니다.

1. 처리하는 정보와 목적

정보처리 시점과 목적
닉네임, 이메일, Google·Apple 사용자 식별자, DavaQ 사용자·세션 식별자와 인증 상태Google·Apple 로그인, 계정 생성·연결, 프로필 표시, 계정 관리와 보호. 검증된 동일 이메일의 기존 DavaQ 계정을 확인해 연결할 수 있습니다. 기본 닉네임은 이메일 앞부분으로 생성될 수 있으며 내 설정에서 변경할 수 있습니다.
직접 등록한 프로필 사진·소개, 보유·희망 카드의 이름·식별자·상태·수량·사진·메모·분류, 공개 오퍼와 댓글선택한 프로필·보유 카드 관리, 교환·나눔 게시와 소통. 비공개 보유 메모와 공개 오퍼 설명은 공개 범위가 다릅니다.
직접 입력한 카드 구매 가격, 교환 조건·제안·진행 상태와 거래 이력카드 관리와 교환 진행. DavaQ는 결제·송금·현금화 또는 암호화폐·NFT 판매·보상 기능을 제공하지 않습니다.
채팅 본문·캡션, 발신자·방·참가자·읽음 상태, 선택하거나 촬영해 보내는 사진·영상 및 선택한 음성·음악·기타 오디오·문서, 파일명·크기·형식메시지 전달·동기화와 파일 공유. 메시지·첨부 참조는 데이터베이스에, 업로드 파일은 객체 저장소에 보관됩니다. 파일 선택기를 이용해 선택한 오디오·문서도 전송할 수 있습니다.
앱 내 친구·차단·그룹 참여 관계, 통화 상대·방·시각·연결 상태, 실시간 음성·영상과 통화 진단친구·초대·그룹 대화, 음성·영상통화와 연결 안정성 관리. 앱 내 관계 정보이며 기기 주소록 전체를 수집한다는 뜻은 아닙니다. 실시간 통화 전송과 통화 상태 기록은 구분하여 처리합니다.
위치 기능 선택 시 얻은 좌표, 직접 입력·선택한 지역과 교환 장소, 조회한 지도 영역주변 카드 검색, 지역에 따른 교환 항목 표시와 장소 안내. 위치 대신 지역을 직접 지정할 수 있습니다. 지도·오퍼 좌표는 소수점 둘째 자리로 반올림하지만 동네 수준의 위치가 드러날 수 있습니다.
검색어·카드 이름·게임·세트·번호, 제출한 스캔 사진과 상태·결과, 직접 요청한 AI 보조 텍스트와 관련 카드 후보 정보카드 검색·시세 조회·사진 식별, 요청한 거래 보조와 답변 제공. 검색 기능에 따라 사용자 식별자·검색어·결과 수·시각을 기록할 수 있습니다.
좋아요·댓글·작성·거래 활동, 신고 사유·대상 참조·상태·검토 기록피드·소통 기능, 신고 처리, 분쟁·부정 이용 대응. 권한 있는 운영자가 신고된 대상을 조회·검토할 수 있습니다.
푸시 토큰·구독·설치 식별자, 앱·기기·운영체제·SDK 정보, 요청 IP·경로·응답 상태·지연, 정제된 통화 진단과 SDK 기술·사용 지표메시지·통화 알림, 서비스 운영, 기술적 이용·오류 분석, 보안과 계정 보호. 설치 초기화와 운영체제의 알림 표시 권한은 별도로 동작할 수 있습니다.
문의 내용과 계정 소유 확인에 필요한 정보고객지원, 정보 열람·정정·처리 정지·동의 철회와 삭제 요청 처리

로그인·계정과 기본 닉네임, 기능 운영에 필요한 이용·설치·진단 정보는 기본 서비스 제공 과정에서 처리됩니다. 카드·메시지·미디어·통화·위치·검색·스캔 등 개별 기능과 추가 프로필 정보는 사용자가 해당 기능을 선택하거나 정보를 제출할 때 처리합니다. 특정 권한을 거부해도 설치·진단 등 일부 SDK 정보 처리가 모두 중단되는 것은 아닙니다.

신규 기본 로그인은 Google·Apple이며, Clerk 인증 SDK 초기화와 기존 로그인 세션 호환 경로도 유지되어 필요한 인증·클라이언트 정보를 처리합니다.

2. 공개 범위와 전달 대상

기본 닉네임과 DavaQ 공개 사용자 ID는 다른 이용자의 프로필 조회에 표시될 수 있습니다. 이메일 앞부분으로 생성된 기본 닉네임도 공개될 수 있으므로 원하는 표시 이름으로 변경해 주세요. 로그인 제공자의 식별자나 이메일 주소를 공개 사용자 ID와 동일하게 공개하는 것은 아닙니다.

직접 등록한 공개 프로필·카드·오퍼·댓글·지역 정보는 해당 화면을 볼 수 있는 이용자에게, 채팅과 공유 파일은 해당 대화 참가자에게, 실시간 음성·영상은 통화 참가자에게 전달됩니다. 거래 제안과 진행에 필요한 정보는 거래 상대에게 표시됩니다. 공개하거나 상대에게 전달한 내용은 다른 이용자가 별도로 저장할 수 있습니다.

신고 처리에는 사유와 대상 참조·검토 기록이 사용됩니다. 신고 큐에 대화 전체나 미디어 사본을 자동 복사하는 방식은 아니며, 권한 있는 운영자가 신고된 대상의 내용을 확인할 수 있습니다.

이용자 데이터를 별도 광고·판매 목적으로 제공하지 않습니다.

3. 검색·사진 인식·AI

TCGIndex는 DavaQ와 동일 운영 주체의 내부 서비스입니다. 카드 검색·시세 조회를 위해 검색어·카드 정보가 이 내부 서비스로 전달됩니다. 사진 스캔을 제출하면 업로드한 이미지가 DavaQ 서버·저장소를 거쳐 TCGIndex 사진 인식 경로로 전달되며 스캔 상태와 결과를 처리합니다.

AI 보조를 직접 요청하면 요청 텍스트와 관련 카드 후보 최대 10개의 식별자·이름·상태·가격·교환 방식·지역 등이 공식 OpenAI API로 전달됩니다. 이는 사용자가 요청한 답변·거래 보조를 제공하기 위한 처리입니다.

Android의 ML Kit 문자 인식은 기기 내에서 수행됩니다. 이 입력 사진·인식 결과 처리와 별도로, Google ML Kit은 설치 식별자, 기기·앱 정보와 처리 지연·입출력 크기·해상도·설정·이벤트·오류 코드 같은 SDK 기술·사용 지표를 Google에 전송할 수 있습니다. 이는 별도로 제출하는 TCGIndex 서버 스캔과 다른 경로입니다.

이용자가 선택한 게시·대화·통화 상대에게 전달되는 내용, 서비스 제공에 필요한 외부 처리, 동일 운영 주체의 내부 처리는 각각의 기능 범위에서 이루어집니다. 외부 처리 경로를 사용한다는 사실과 데이터를 광고·판매 목적으로 제공하는 것은 구분합니다.

5. 기기 권한과 로컬 데이터

카메라는 촬영·스캔·영상통화에, 마이크는 음성·영상통화와 선택한 영상 촬영의 오디오에 사용합니다. 사진·영상·파일은 사용자가 선택한 자료를 전송·등록하는 데 사용합니다. 위치는 사용자가 위치 기능을 선택할 때 주변 검색·장소 지정에 사용하며 지역을 직접 지정할 수도 있습니다. 필요한 권한은 기기 설정에서 변경할 수 있습니다.

진행 중인 통화는 화면을 벗어나도 계속될 수 있으며 통화를 종료하거나 기기 권한을 변경해 마이크·카메라 사용을 중지할 수 있습니다. 수신 전화 전체 화면 표시와 일반 알림 표시 설정은 별도로 제공됩니다.

화면을 빠르게 표시하기 위해 메시지·미디어 일부가 기기에 캐시될 수 있습니다. 캐시 정리나 브라우저 저장 데이터 정리는 서버의 메시지·파일 전체 삭제와 다릅니다. 사용자가 기기 갤러리에 따로 저장한 사본도 별도 파일입니다.

커뮤니티 규칙의 작성 동의 상태는 현재 기기에 DavaQ 계정·규칙 버전별로 저장합니다. 다른 기기나 저장 데이터 정리 후에는 다시 확인할 수 있습니다.

6. 보관과 파기

계정·프로필·카드·게시물·대화·교환 등 서비스 기록은 서비스 제공에 필요한 이용 기간 동안 보관합니다. 이용자가 직접 지우거나 계정·데이터 삭제를 요청하면 본인 확인 후 요청 범위에 따라 삭제 또는 개인을 식별할 수 없도록 처리합니다. 화면에서 메시지를 숨기는 동작이나 로그아웃, 앱 삭제만으로 서버의 모든 데이터가 삭제되는 것은 아닙니다.

미완료 교환, 신고·분쟁 처리, 보안·부정 이용 조사 또는 법령상 보관 의무로 일부 정보를 보관해야 한다면 해당 목적에 필요한 정보만 분리하여 보관하고, 삭제 요청 처리 시 대상·사유·보관 기간을 안내합니다. 사유가 종료되면 파기합니다. 백업에 포함된 데이터는 즉시 개별 삭제가 되지 않을 수 있으며, 해당 경우 처리 결과와 남은 보관 범위를 안내합니다.

7. 권리행사와 계정·데이터 삭제

정보 열람·정정·처리 정지·동의 철회·계정 및 데이터 삭제는 contact@smileon.app으로 요청할 수 있습니다. 닉네임·소개 등은 앱의 내 설정에서도 변경할 수 있습니다.

현재 삭제 요청은 운영팀이 본인 확인 후 처리하는 수동 접수 방식입니다. 가입 이메일과 프로필 이름, 전체 또는 특정 데이터 등 요청 범위를 알려 주세요. 비밀번호·인증번호·신분증 사본은 보내지 마세요. 가입 이메일을 사용할 수 없다면 필요한 최소한의 본인 확인 방법을 별도로 안내합니다.

계정·데이터 삭제 요청 안내에서 제출 방법과 처리 범위를 확인할 수 있습니다. DavaQ에서의 삭제 요청은 Google·Apple 계정 자체의 삭제 요청과 다릅니다.

8. 보호 조치와 안내 변경

API·파일 저장소의 HTTPS, 통화 연결의 WSS, 데이터베이스의 TLS 등 전송 구간 보호를 사용합니다. 인증과 접근 권한을 적용하고, 자체 소셜 인증의 서버 세션·접근 토큰은 해시로 관리합니다. 공개 게시물과 채팅에 비밀번호·인증번호를 올리지 마세요.

처리 목적·항목·제공 대상 등이 바뀌면 이 페이지의 적용일과 내용을 갱신하고 필요한 경우 앱을 통해 알리거나 별도 동의를 받습니다. 문의와 권리행사는 SmileOn Labs DavaQ 운영팀의 contact@smileon.app으로 보내 주세요.
