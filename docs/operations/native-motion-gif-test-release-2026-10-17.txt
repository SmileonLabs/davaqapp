실기기 검증 (앱 삭제 없이 업데이트)
모션 확인 시 먼저 시스템 진동을 허용하고 iOS 동작 줄이기 / Android 애니메이션 삭제를 끈다.
마지막 단계에서는 다시 모션 감소를 켜 접근성 동작도 별도로 확인한다.
0. 업데이트 버전이 iOS1.0.0(36) 또는 Android1.0.0(54)인지 확인하고 앱을 완전히 종료한 뒤 다시 실행한다.
   채팅 목록의 수집AI수다방이 미참여 상태에도 보이고 대화 미리보기 → 안내 → 참여가 가능한지 확인.
   참여 후 기존 채팅으로 돌아와 일반 대화 전송도 확인한다.
   AI 닉네임/프로필 사진 → 소개 → 친구 추가를 확인하고, 안내 확인 후 1:1 대화를 시작한다.
   1:1에서 보낸 고유한 문장이 공개방에 나타나지 않는지 확인한다.
   원격 안내 문구는 관리자 웹에서 변경 후 앱을 다시 열거나 30초 이상 기다려 반영을 확인한다.
   AI 문구 설정 테스트가 끝나면 원래 값으로 복원한다.
1. 하단 설정 탭이 항상 보이고 설정 화면으로 이동되는지 확인. 기존 프로필 사진 유지 확인.
2. 텍스트/사진/스티커 말풍선을 길게 눌러 눌림·탄성·진동·단일 메시지 포커스를 확인.
   답장·복사·반응 취소·다중 선택이 기존처럼 동작하는지 확인.
3. 말풍선 왼쪽 스와이프는 답장, 배경 오른쪽 스와이프는 뒤로가기인지 확인.
   천천히 끌다가 취소·빠르게 완료·iOS 가장자리 완료/취소를 각각 확인.
   긴 대화를 읽다가 뒤로 나간 뒤 다시 진입해 읽던 메시지 위치가 복원되는지 확인.
4. 스티커 페이지를 좌우로 끌고 이전/다음 버튼도 사용. 첫/마지막에서 빈 페이지가 남지 않는지 확인.
5. 스티커를 선택해 위로 이동하는 효과와 말풍선 생성 확인. 연속 선택도 한 번씩만 전송되는지 확인.
6. GIF 탭에서 cat/dance/happy 등을 검색하고 하나를 보내 상대 기기에서 움직이는지 확인.
   메시지의 출처/라이선스 표기 확인. 기기 GIF 선택도 반복한다.
7. GIF 전송 후 앱 종료·재실행, 다른 기기 로그인 후 동일 이미지·출처 표시 확인.
8. 비행기 모드에서 텍스트·스티커 전송 후 앱 종료 → 재연결·재실행하여 중복 없이 복구되는지 확인.
   연결이 끊긴 동안 상대 기기에서 보낸 메시지가 누락 없이 수신되는지 확인.
9. GIF 다운로드 중 계정/방을 바꾸었을 때 새 방에 잘못 전송되지 않는지 확인.
10. 동작 줄이기(모션 감소)를 켜고 앱을 다시 실행한 뒤 전송·메뉴·스와이프가 계속 동작하는지 확인.
