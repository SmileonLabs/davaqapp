P1 정책과 범위
- 전송 대기 본문 보존 기간: 기존 24시간 -> 30일. 로그아웃/계정 전환 시 해당 계정 데이터 삭제 유지.
- 자동 재시도: 기존 30분/8회 -> 7일/4096회, 최대 5분 backoff 및 회당 3건 처리 유지.
- 수동 재시도는 원래 clientMessageId와 생성 시각을 유지하면서 retryStartedAt만 갱신한다.
- 기존 확정 실패는 자동으로 재활성화하지 않는다. 프로필 없는 과거 항목도 다른 프로필로 발송하지 않는다.
- 로컬 대화: 계정+프로필+방 단위, 500개 메시지/최근 20개 방/30일의 복원 캐시.
  PWA는 IndexedDB, 네이티브는 기존 AsyncStorage 사용. 전체 서버 기록은 서버가 원본이다.
- 본문과 변경 revision은 하나의 저장 단위로 함께 기록한다. 저장 실패 시 둘 다 이전 상태다.
- 서버 응답이 실제 Query 캐시에 반영된 뒤 저장하며, 세대 번호와 계정 잠금으로 로그아웃 뒤 늦은 저장을 차단한다.
- 읽음 성공/다른 기기의 읽음 이벤트는 최신 메시지까지 읽었을 때 배지를 즉시 0으로 반영한다.
  부분 읽음은 sequence 차이로 수를 추정하지 않고 서버의 확정 unreadCount를 다시 받는다.
- 서버 unreadCount/firstUnreadMessageId는 전체 삭제와 개인 삭제 메시지를 제외한다.
- 로컬 데이터 보존 만료/용량 제한 및 서버 삭제 이력 반영을 테스트한다.
