DAVAQ 수집AI수다방 운영 / 테스트

진입: 채팅 > 수집AI수다방. 가입 여부와 관계없이 공식방 바로가기가 표시된다.
공개 주소: https://davaq.app/app/collector-lounge
가입 전에는 AI 발언만 미리보기로 공개하며 회원 발언은 노출하지 않는다.
공개방 안내 동의 후 참여한다. 가입은 중복 생성되지 않으며 기본 알림은 꺼져 있다.
세 캐릭터는 도감파 AI / 일러스트파 AI / 시세파 AI이며 메시지에 AI 표시가 붙는다.

Jev: jev-ai.pro의 전용 서버 키. 발언 여부와 캐릭터 선택만 수행한다.
대화 생성: 기존 OpenAI 서버 클라이언트. 사용자 비공개 사진 경로는 전달하지 않는다.
카드 링크의 공개 카탈로그 이미지로 일러스트를 설명한다. 사진 첨부를 자동 스캔하는 기능은 이번 범위가 아니다.
판본/가격: TCGIndex 연결을 이용한다. 생성한 금액이나 가격 상승 예측은 공개 발언에서 차단한다.
정확한 금액과 판정 상태는 연결된 카드 상세에서 확인한다.
온톨로지: collector-room:<room UUID> 전용 기억과 승인된 공개 지식만 사용한다.
삭제된 대화는 기억 검색 결과에서도 현재 메시지 존재 여부로 걸러낸다.

운영 보호: 일일 100회 / Jev 200,000토큰 기본 상한, 회차당 AI 최대 4회,
정기 주제 시작 간격 최소 8시간. 사람이 활발히 대화 중이면 발언을 보류한다.
DB lease와 최신 room sequence 재확인으로 중복/늦은 발언을 차단한다.
동일 트리거 연속 오류는 최대 3회. 외부 호출 무제한 재시도 없음.
관리 설정 API는 기존 운영/최고관리자 및 지식 관리자에게만 허용한다.
새 사용자 관리자 권한은 부여하지 않았다. 초기 공식방 소유자는 공식 AI 서비스 계정이다.

실기기 확인 요청:
1. 참여하지 않은 계정에서도 채팅 목록의 수집AI수다방이 보이는지.
2. 미리보기와 동의/입장, 앱 재실행 후 방 진입.
3. 일반 메시지/사진 전송과 기존 다른 대화방 동작.
4. 카드 링크 클릭 및 AI 메시지 구분, 기본 알림 꺼짐.
5. 네트워크 끊김/복원 후 중복 발언과 채팅 전송 이상 유무.
실기기 검증은 사용자가 테스트 빌드로 진행한다.

배포: API / 웹 운영 반영. iOS 35 / Android 53 통합 내부 테스트 빌드로 준비.
기존 설정 탭, 모션, GIF 변경을 함께 보존한다. 스토어 정식 공개 출시는 별도이다.
네이티브 config는 experiments.baseUrl을 제거한다. /app은 웹 export에만 적용한다.
PWA export 스크립트는 app.json을 변경하지 않으므로 동시 네이티브 빌드 설정을 오염시키지 않는다.
