초기 자동 잠금 방지 구현의 수명과 검증

화면 대신 통화 제공자에 화면 유지 처리를 연결해 축소·채팅 이동에도 유지한다. 서로 다른 통화 소유자는 독립 태그를 쓴다. 활성화 중 종료되는 비동기 경합을 직렬화해 뒤늦게 잠금 방지가 남지 않게 했다. 지원하지 않는 브라우저나 OS 거절은 통화 연결·종료를 실패시키지 않는다. 수신 벨 대기만으로는 화면 유지 권한을 잡지 않는다.

최초 단계에서 화면 유지 테스트 6개와 기존 연결 복구·통화 시도·통화음 테스트를 합친 17개 및 모바일 TypeScript 검사가 통과했다. iOS·Android 네이티브 번들 export도 모두 통과했다. 설치·스토어 배포나 실제 통화 검증을 뜻하지는 않는다.

실기기 확인 방법

  1. iPhone·Android의 자동 잠금을 짧게 설정하고 1:1 음성·영상, 그룹 음성·영상 각각에서 설정 시간의 두 배 이상 화면을 만지지 않는다. 전경 통화 화면과 축소 후 채팅 화면 모두 자동 잠금이 없어야 한다.
  2. 종료·발신 취소·상대 거절·로그아웃 후에는 평소 자동 잠금이 다시 적용되어야 한다.
  3. 통화 중 홈으로 나가면 기존 백그라운드 통화가 유지되고 화면 유지 권한은 해제되어야 한다. 앱으로 돌아오면 전경 화면 유지가 재개되어야 한다.
  4. 연결 직후 즉시 종료, 빠른 전경/배경 전환, 종료 직후 재통화를 반복해 잠금 누수·새 통화 권한 해제가 없는지 확인한다.
  5. Wi-Fi↔셀룰러 전환 후 같은 통화로 복구되는지, 음성과 영상의 준비 상태가 별도로 표시되는지, 복구 중에도 종료할 수 있는지 확인한다.

후속 통화 개선 구현·검증

자동 잠금 방지, 실제 미디어 연결부터 시작하는 통화 시간, 음성 복귀 바·이동 가능한 미니 영상, 로컬 카메라 미리보기·음성으로 받기, 영상 맞바꾸기·드래그 구분·조작 숨김, 그룹 출력·카메라 전환·발언 상태, 종료 안내·재시도를 구현했다.

늦은 권한 응답·취소·계정 전환·카메라 자원 정리와 재시도 대상 회원 ID를 검증했다. 배너 변경 시 채팅 하위 화면을 재생성하지 않으며 실제 컴포넌트 검증 페이지에서 상태 유지·영상 드래그·맞바꾸기·조작 숨김을 확인했다.
