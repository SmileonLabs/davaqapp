PWA photo cache improvement (source implementation)

Private photos and legacy HEIC display JPEGs now share an account/path memory cache.
Concurrent loads share a single request and conversion. Remounts synchronously reuse
available memory URLs; releasing a component does not immediately revoke shared URLs.
Browser CacheStorage persists display blobs with a 64 MiB / 80 item / 7 day bound.
Memory pruning evicts inactive entries, preserving images currently displayed.
Account switch/logout fences pending work and deletes the previous account cache.
Storage denial/quota errors fall back to displaying fetched photos.
Explicit retry evicts the cached copy and reacquires an authorized URL.
Normal photo uploads retain their existing thumbnail and server-original behavior.
This change does not create server thumbnails or change original storage files.
