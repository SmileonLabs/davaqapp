사용자가 할 실기기 검증
앱 데이터가 유지되는 업데이트 방식으로 설치하고 표시되는 빌드 번호31/48을 확인한다.
A계정 기기와 같은 계정의 다른 기기/웹, B계정 상대를 준비하고 전용 검증 방만 사용한다.
1. 과거100개 이상 탐색→방 이동→앱 종료/재실행 후 읽던 메시지 부근 복원.
2. 화면 위/아래 메시지, 긴 글/사진을 길게 눌러 포커스 메뉴 표시 및 닫기 후 위치 유지.
3. 본문 왼쪽은 답장, 빈 배경 오른쪽은 뒤로가기, 수직은 스크롤. 짧은 스와이프는 취소.
4. 두 계정이 같은 반응을 추가해 숫자2→A 취소 후1. 다른 기기/재접속 후도 일치.
5. 여러 메시지 복사/전달/나에게만 삭제. 중간 연결 실패 후 남은 항목만 재시도, 중복 없음.
6. 스티커 분류/검색/다음 페이지에서 실제 애니메이션 재생과 상대 기기 수신 확인.
   아직 열지 않은 분류를 비행기 모드에서 열어 로컬 애니메이션이 표시되는지도 확인.
7. 오프라인 메시지/스티커 전송→앱 종료→상대 G1/G2/G3 전송→재연결.
   대기 메시지는 정확히1개 전달되고 누락 메시지는 순서대로 복구돼야 한다.
8. 잠금 상태에서 상대의 테스트 알림 수신 및 탭 시 올바른 방으로 이동.
