DavaQ UI 6개 개선 / 2026-10-17 KST

반영 내용
1. 스티커 그리드 좌우 스와이프로 이전/다음 페이지. 분류 가로 스크롤은 별도로 유지.
   48px 이상 수평 이동에서 한 페이지 이동하고 양 끝에서는 멈춘다.
   수직 스크롤·짧은 드래그는 페이지를 바꾸지 않고 스티커 전송도 하지 않는다.
2. 채팅의 빈 배경 탭으로 스티커·첨부 패널·키보드를 닫는다. 입력한 초안은 유지한다.
   메시지 본문 터치·길게 누르기·스크롤과 구분한다.
3. 직접 선택한 DavaQ 프로필 이미지를 우선 유지한다.
   기본 이미지는 프로필 UUID를 고정된 v1 카드 풀12종에 매핑한다.
   무작위 분산에 해당하는 고정 해시 방식으로 새 DB 기록 없이 기기/재설치/이름 변경에도 같다.
   v1 이미지 목록 순서는 변경하지 않는다. 비공개 외부 계정 사진은 공개하지 않는다.
4. 채팅 배경 뒤로가기 스와이프에서 화면 하나만 밀어 빈 영역을 드러내던 처리를 제거했다.
   임계값을 통과하면 버튼과 같은 navigator 뒤로가기 전환을 사용한다.
   손가락을 따라 화면이 움직이는 별도 전환은 사용하지 않는다.
5. 컬렉션 썸네일은 내 업로드 사진 → 캐시된 카탈로그 이미지 → 카드 상세 이미지 순서로 표시한다.
   API는 기존 카탈로그 테이블을 읽어 image_src를 추가한다. 사진이나 컬렉션 데이터는 변경하지 않는다.
6. 컬렉션 상단 메뉴를 제거하고 목록 하단에 '설정' 버튼을 배치한다.

실기기 확인 방법
앱 삭제 없이 TestFlight32 / Play 내부 테스트49로 업데이트한다.
1. 스티커 영역을 좌/우로 밀어 페이지를 넘긴다. 처음/끝, 분류 전환·검색 후 첫 페이지를 확인한다.
   스티커를 탭할 때 한 번만 전송되고, 페이지를 밀 때는 전송되지 않아야 한다.
2. 초안을 입력한 뒤 스티커를 열고 빈 채팅 배경을 탭한다.
   패널·키보드가 닫히고 초안은 남아야 한다. 다시 열어 스크롤/메시지 길게 누르기도 확인한다.
3. 원래 업로드 사진이 있던 계정은 같은 사진인지 확인한다.
   사진이 없던 계정은 새 iOS·Android 빌드에서 같은 카드인지, 이름 변경/재로그인 후도 유지되는지 확인한다.
4. 대화방 배경을 오른쪽으로 밀어 뒤로가기와 취소를 각각 확인한다.
   전환 중 흰 빈 화면이 번쩍이지 않아야 하며 메시지 왼쪽 답장은 그대로 동작해야 한다.
5. 사진 없이 등록한 카드와 직접 사진을 올린 카드의 컬렉션 썸네일을 대조한다.
   상세 화면에 표시되는 카드가 목록과 같고, 로딩 후 실제 이미지가 나타나는지 확인한다.
6. 컬렉션 목록 하단의 '설정'으로 기존 설정 화면이 열리는지 확인한다.
7. 오프라인에서 메시지/스티커 입력→앱 종료→상대가 G1/G2/G3 전송→재연결한다.
   대기 전송은 한 번만 도착하고 G1/G2/G3은 빠짐없이 순서대로 복구되어야 한다.
8. 과거 대화를 읽다가 다른 화면을 왕복하고 앱을 재실행해 읽던 위치를 확인한다.
   반응 취소·동일 계정 두 기기 동기화·잠금 푸시 수신/탭 이동도 확인한다.
