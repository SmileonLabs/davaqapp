DavaQ 6개 UX 적용 누락 재점검 / 2026-10-17 KST

판정
기존 iOS32/Android49의 서명된 배포 파일에는 수정 코드가 포함되어 있었다.
그러나 코드의 일부 경로만 수정되어 화면별 적용이 불완전했다. 사용자 업데이트 실수로 보지 않는다.
연결된 iPhone의 실제 설치 버전도 devicectl에서 1.0.0(32)로 확인했다.
Mac iPhone 미러링은 연결 실패, Android ADB 목록은 비어 있어 실기기 터치 재현 완료로 기록하지 않는다.
기존 소스/배포 파일 해시와 운영 API 배포 영수증은 .local/releases/ux-six-20261017/에 보존했다.
이전 완료 안내는 화면별 검증이 충분하지 않았다. 이번 기록이 해당 적용 상태를 대체한다.

실제 누락과 수정
1. 스티커 스와이프: 그리드 자식 Pressable보다 부모가 수평 움직임을 먼저 판정하도록
   onMoveShouldSetPanResponderCapture 추가. 분류 가로 스크롤과 분리, 짧은/수직 이동 무시 유지.
2. 배경 탭: FlatList keyboardShouldPersistTaps를 always로 바꿔 키보드가 열려 있을 때도
   빈 배경 탭이 패널 닫기 경로로 전달되게 했다. 메시지 터치·스크롤 구분과 초안 유지 검사 유지.
3. 프로필: 설정 화면의 고정 Cue를 실제 활성 프로필 Avatar와 사진 편집 진입으로 교체.
   /users/me는 항상 null, 검색/추천은 원본 값을 쓰던 API 경로를 공통 공개 아바타 정책으로 정리.
   방 멤버·친구 목록·과거 메시지의 원본 프로필 직렬화도 같은 정책으로 정리했다.
   선택 사진과 기본 카드 모두에서 방/친구/전송 응답/재조회 응답이 일치하는 실제 검사를 추가했다.
   공개되지 않은 외부 계정 사진은 차단하고 명시적으로 고른 업로드 우선/기본 카드 고정 매핑 유지.
4. 전환: Android는 수동 이동을 없앤 뒤에도 transparentModal 설정이 남아 있었다.
   네이티브는 불투명 card 전환, iOS는 시스템 가장자리 인터랙티브 뒤로가기 사용.
   화면 중앙의 빈 배경 오른쪽 이동은 기존 임계값과 버튼의 navigator.back 경로를 사용한다.
   iOS 왼쪽24px에서는 사용자 정의 PanResponder가 시스템 제스처를 가로채지 않는다.
   다중 선택/포커스 메뉴 중에는 시스템 제스처도 꺼서 기존 선택 취소 동작과 충돌하지 않는다.
5. 컬렉션: 보유 탭만 적용된 썸네일을 공통 CollectionCardArt로 옮겨 희망/내 매물/거래 기록
   및 관련 소유 카드 선택 경로에도 사용한다. 희망 API도 카탈로그 캐시의 image_src를 포함한다.
   업로드 사진 → 카탈로그 캐시 → 상세 조회 순서를 유지한다.
6. 설정 위치: 목록 끝에 붙어 있던 버튼을 Frame의 스크롤 밖 footer로 이동했다.
   하단 탭 영역을 확보하고 목록 길이에 관계없이 화면 하단에서 접근한다.

캐시 확인
- 네이티브는 APK/IPA에 들어간 JS 번들을 실행하며 PWA 서비스워커 경로와 구분한다.
- QueryClient는 세션 메모리 캐시이며 프로필/카드 캐시 전체를 지우거나 채팅 DB를 초기화하지 않았다.
- 별도 전역 davaq-avatar-profile 캐시를 제거하고 사진 편집도 useCharacterProfiles를 공유한다.
- 설정 화면 재진입 시 활성 프로필을 새로 조회한다. 사진 저장 후 기존 invalidateQueries 유지.
- 새 빌드에 대해 API 주소·카드 목록·212종 자원·소스 해시·서명을 다시 확인한다.

실기기 확인 순서
앱을 삭제하지 않고 TestFlight33 / Play 내부 테스트50으로 업데이트한다.
1. 내 설정에서 실제 프로필 사진/고정 카드가 보이고 사진 변경 화면으로 진입되는지 확인.
   이미 직접 설정한 사진이 유지되는지, 다른 회원의 검색/채팅/프로필 사진이 일치하는지 확인.
2. 컬렉션 보유·희망·내 매물·거래 기록의 이미지를 각각 확인한다.
   사진 없이 등록한 카드도 보여야 하며 직접 업로드한 사진을 카탈로그로 덮어쓰면 안 된다.
3. 컬렉션을 스크롤해도 하단 설정 버튼이 고정되고 하단 탭과 겹치지 않는지 확인.
4. 스티커 위에서 좌우 스와이프한다. 스티커가 전송되면 안 된다. 분류 가로 이동은 별도로 확인.
5. 초안 입력→스티커 열기→빈 배경 탭. 키보드와 패널이 닫히고 초안은 남는지 확인.
   수직 스크롤/말풍선 길게 누르기/왼쪽 답장이 배경 탭이나 뒤로가기로 오인되지 않아야 한다.
6. iOS 왼쪽 가장자리에서 뒤로가기와 중간 취소를 확인하고 Android 배경 오른쪽 이동을 대조한다.
   흰 빈 화면이 나타나는지 확인한다. 중앙 스와이프는 임계값 이후 화면 전환이다.
7. 오프라인에서 전송→앱 종료→상대 G1/G2/G3 전송→재접속.
   대기 메시지1회 전달/누락 복구/읽던 위치/다중기기 반응 취소 동기화를 확인한다.
8. 잠금 푸시 수신과 알림 탭의 올바른 방 진입을 확인한다.
