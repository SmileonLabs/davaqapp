# DavaQ 모바일 화면 시안 v1
작성일: 2026-09-12
제작: 내장 image_gen 도구. 운영 화면의 캡처가 아닌 생성형 디자인 시안입니다.
목적: 메신저 기반 교환과 개인 AI 성장 기능의 주요 화면을 함께 검토합니다.
원본 크기: 각 1536 × 1024 PNG, 보드마다 3개 모바일 화면.

하단 메뉴: 홈 / 둘러보기 / 채팅 / 내 AI / 내 교환.
등록·상품 상세·매칭 추천·협상 대화는 세부 화면으로 진입하며, 하단에는 해당 화면의 행동 버튼 또는 메시지 입력창을 둡니다.

- [01 홈·둘러보기·내 AI](01-home-discover-agent.png)
- [02 채팅·교환 협상·내 교환](02-chat-negotiation-exchanges.png)
- [03 AI 등록·Experience 상세·AI 추천](03-registration-experience-matching.png)
- [생성 프롬프트와 보정 기록](prompts.md)

첫 보드를 스타일 참조로 사용해 나머지 두 보드를 제작했습니다. 세 번째 보드의 매칭 카드에서 받는 항목의 작은 제목을 “내가 받을 것”으로 보정했습니다.

프로필 인물·대화·일정·상태는 예시입니다. Experience 구성과 EV도 제품 계획의 예시이며, 공개 운영 데이터나 실제 교환 완료를 의미하지 않습니다. 텍스트와 세부 수치는 실제 구현 시 디자인 컴포넌트로 다시 작성합니다.
