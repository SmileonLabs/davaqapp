# DavaQ 공통 메신저

큐 대화와 사람 간 대화가 같은 입력창, 말풍선, 사진·파일 첨부, 전송 대기함, 재시도, 메시지 순서 복구를 사용한다. 큐의 기억과 AI 작업은 DavaQ 전용 저장소에 유지한다. AnotherMe 소스·앱 데이터에는 변경이 없다.

## 사용자 흐름

- 채팅 목록 상단에 나의 큐와 최근 메시지를 고정한다.
- 질문은 전송 대기함에 먼저 저장하고 서버 접수 즉시 표시한다. AI 답변을 기다리는 중에도 다음 메시지를 보낼 수 있다.
- 큐의 답변에 실제 교환 후보 카드, 브랜드 혜택 카드, 확인할 기억 카드를 붙인다.
- 교환 제안 카드에서 기존 제안 확인 화면으로 이동하고, 사용자가 제안하면 상대방과의 기존 채팅방으로 연결한다.
- 기억은 사용자가 승인해야 확정된다. 삭제·거절한 기억, 차단·비공개 처리된 교환, 종료된 브랜드 혜택은 카드 조회 시 다시 확인한다.

## 구현

`chatTransport.ts`가 일반 대화는 기존 room API로, 큐 대화는 `/agents/me/conversation/messages`로 연결한다. 두 대화 모두 기존 `useChatSendHandlers`, `ChatOutboxDrainer`, `useReliableRoomMessages`, `MessageComposer`, `MessageBubble`, `ChatRoomHeader`를 사용한다. 큐 대화 캐시와 전송 대기함의 대화 ID에는 로그인 계정 ID를 포함한다.

마이그레이션 0034는 기존 `agent_messages`를 보존하면서 순서 번호, 미디어 종류, 작업 상태, 답변 카드 참조를 추가한다. 접수한 질문을 사용자별 순서대로 처리하고, 만료된 작업 임대는 복구한다. 임대 토큰과 요청 ID가 중복 답변을 막는다. 시간당 접수 한도 이후에도 동일 요청의 재전송은 허용한다. 이전 큐 API도 같은 접수 경로를 사용한다.

첨부 파일은 업로드 소유자를 확인하며 외부 URL이나 다른 계정의 첨부를 허용하지 않는다. 현재 사진·파일은 전송·열람할 수 있고 큐는 설명을 추가로 묻는다. 이미지 내용 분석과 문서 내용 추출은 이번 변경에 포함되지 않는다. 큐 대화의 서버 갱신은 응답 대기 중 1.5초, 유휴 상태 15초의 전경 폴링이다. 사람 간 대화는 기존 실시간 연결을 사용한다.

## 검증

- 임시 PostgreSQL에서 전체 마이그레이션 및 교환·리워드·큐 대화 통합 검증 98개 통과.
- 기존 메시지 재시도·캐시·계정 경계·재접속 검증 44개 통과.
- 공통 전송 어댑터 검증 4개, 기존 교환·리워드 단위 검증 14개 통과.
- 실제 큐 화면과 공통 메신저 구성요소를 브라우저 테스트 환경에서 실행: 즉시 메시지 표시, 비동기 답변, 교환 제안 경로, 기억 승인, 전송 실패와 동일 요청 ID 재시도, 모바일·데스크톱 표시 확인. 테스트용 인증·응답·네이티브 모듈 어댑터를 사용했으며 운영 계정의 실거래는 생성하지 않았다.
- 브라우저 검사에서 발견한 비활성 말풍선의 중첩 재시도 버튼 문제를 수정했다. 길게 누르기가 없는 메시지는 비활성 Pressable 대신 View를 사용한다.

## 배포

기존 DavaQ 배포 스크립트로 DB 백업 후 0034를 적용하고 API와 PWA를 함께 갱신한다. `davaq-chat-20260922-v1` 캐시 버전을 사용한다. 로그인·OpenAI·LiveKit 설정은 기존 DavaQ 설정을 유지한다. 배포 성공 여부는 실제 배포 결과로 별도 확인한다.


## 메신저 기능 복원 (2026-09-22)

- 채팅 목록에서 친구 목록·추가·초대·받은 요청·그룹 생성·알림 설정으로 이동한다. 안 읽음, 그룹, 교환 상태와 기존 그룹 카테고리 필터를 제공한다.
- HTTPS 초대 링크는 로그인 전에도 열 수 있다. 초대 코드를 기기에 보관하고 로그인 후 확인 화면으로 연결하며, 요청 전송은 사용자가 확인한다.
- Q 대화에도 기존 공통 메시지 메뉴(답장, 복사, 선택, 고정/해제, 전달, 스티커 반응, 삭제)를 연결했다. 메시지 소유권을 검사하고 삭제한 질문의 대기 작업을 취소한다. 다른 방 전달은 기존 방 권한과 중복 전송 방지 API를 사용한다.
- 일반 1:1 방에서 명시적으로 소환한 AI가 후속 메시지에도 응답한다. 동의 철회·차단·사용자 복귀 시 세션을 종료하고, 각 응답 조각 저장 전 활성 세션을 재확인한다. 자동 인격 생성과 수동 동의 없는 학습은 기존 비활성 상태를 유지한다.
- 기존 음성·영상 통화와 사람 간 채팅 엔진을 유지한다. Q 대화 자체의 음성·영상 통화 기능을 새로 추가한 것은 아니다.

## 성능 개선

대화 목록은 FlatList로 필요한 행만 렌더링하고 행 컴포넌트를 메모이제이션한다. 교환 제안과 대화의 연결은 매번 선형 탐색하지 않고 Map으로 조회한다. 화면을 벗어나면 주기 조회를 중지하며, 친구 검색은 250ms 디바운스를 적용한다.

메시지 동기화는 최신 50개가 기존 커서를 포함하면 추가 조회를 생략한다. 유휴 상태와 작은 갱신에서 메시지 조회가 2회에서 1회로 줄고, 50개를 초과한 공백은 기존 전체 보충 조회로 복구한다. 채팅 목록의 Q 미리보기는 최근 한 메시지 전용 조회를 사용하며 매번 교환·리워드·기억 카드를 재계산하지 않는다.

## 추가 검증 및 배포 범위

- 격리한 PostgreSQL에서 교환·리워드·Q·친구·그룹·일반 메시지·AI 세션 통합 검증 132개 통과. 운영 계정의 친구나 메시지는 만들지 않았다.
- 메시지 신뢰성 검증 57개와 PWA/푸시 검증 7개 통과. 최신 창으로 공백이 복구되는지 확인하는 회귀 검증을 포함한다.
- 실제 DavaQ LiveKit 설정으로 임시 방에 두 자동 브라우저를 연결해 양방향 음성·영상 수신과 디코딩을 확인했다. 카메라 권한이 해결되지 않은 상황에서도 음성과 상대 영상 수신을 확인했다. 테스트용 미디어 장치를 사용했으며 실제 사용자 기기 간 수동 통화 검증과는 구분한다.
- 마이그레이션 0035는 답장 참조·삭제 상태·사용자별 고정 메시지를 추가한다. 기존 사용자별 순서 인덱스를 재사용한다. PWA 캐시 버전은 davaq-messenger-20260922-v2이다.
