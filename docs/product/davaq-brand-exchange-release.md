# DavaQ 브랜드 교환 첫 릴리스 운영 안내

## 제공 범위

- 홈의 **내 1분 바꾸기**, 둘러보기의 브랜드 교환, 큐 채팅의 혜택 안내, 내 AI의 혜택 취향, 내 교환의 **받은 혜택**을 연결했습니다.
- 30초 영상을 동시에 재생하면서 다른 부분 2~3개를 찾습니다. 안내·결과를 합쳐 약 1분이며, 재도전은 약 30초가 추가됩니다.
- 첫 릴리스는 웹/PWA에서 영상 참여를 제공합니다. 네이티브 화면은 웹 이어하기를 안내합니다.
- 캠페인별 한 번 참여하고 두 번까지 도전합니다. 각 도전은 8번 선택, 확보 기간은 20분, 24시간 내 캠페인 시작은 5개까지입니다.
- 쿠폰, 상품 교환권, 디지털 체험권의 **사전 확보 고유 코드**를 지급합니다. 실물 배송이나 외부 쿠폰 발주 API는 포함하지 않습니다.
- EV, 현금 지갑, 다른 사용자와의 교환 제안 데이터와 분리합니다. Q는 실제 후보만 소개하고 사용자 대신 참여·정답 선택·수령하지 않습니다.
- 광고 시청 자체를 선호나 신뢰 점수로 확정하지 않습니다. 사용자가 확인한 기억은 별도 브랜드 활용 동의가 켜졌을 때에만 제한된 관심 분야 추천에 사용합니다. 광고주에게 대화·기억·쿠폰 코드를 제공하지 않습니다.

## 첫 캠페인 등록

1. **내 설정 → 브랜드 교환 운영**에서 브랜드·혜택·사용 조건·추가 결제·문의처·마감일을 입력합니다.
2. 사용 및 수정 허가를 받은 **H.264 MP4** 두 개를 업로드합니다. 파일마다 25MB 이하, 길이 30초(±0.2초), 같은 해상도, 최대 1920px이어야 합니다. 파일의 MP4 길이 메타데이터가 필요합니다. API에서 파일을 변환하지 않습니다.
3. 원본 영상을 이동해 장면을 비교하고 B 영상에 정답 영역을 드래그합니다. 각 차이가 유효한 시간 범위를 지정합니다. 작은 휴대폰에서도 누를 수 있는 크기를 사용합니다.
4. 두 영상과 정답을 검토하고, 원가·예산·보상 확보와 소재 권리를 확인한 후 초안을 저장합니다.
5. 실제 확보한 고유 코드를 한 줄에 하나씩 등록합니다(회당 100개). 공통 유효기간이 7일보다 많이 남아야 합니다. 중복 코드 재등록은 추가 재고를 만들지 않습니다.
6. 최종 공개 사유와 예산을 확인하고 **공개**합니다. 재고·예산·종료일 조건이 충족되어야 공개할 수 있습니다.

캠페인 소재와 보상 조건은 저장 후 고정합니다. 변경하려면 별도 초안을 만들어 검토합니다. 진행 중인 참여는 시작할 때의 버전과 확보 보상을 보존합니다. 등록·공개·재고 추가·지원 처리는 운영 감사 기록을 남깁니다. operations/super_admin 및 기존 비상 관리자만 변경할 수 있고, analyst/support는 조회만 합니다.

## 보상 및 장애 처리

- 참여 시작 트랜잭션에서 재고 한 개와 해당 원가만큼 예산을 함께 확보합니다.
- 순서·브라우저 임대 토큰·양쪽 영상 위치·서버 누적 시간을 검사합니다. 반복 요청과 정답 선택 재전송은 중복 처리하지 않습니다.
- 성공 시 claim과 outbox를 같은 트랜잭션에서 기록합니다. 별도 15초 작업자가 확보된 코드와 암호화 상태를 확인해 지급합니다.
- 이미 성공했거나 지급을 기다리는 참여는 일반 확보 만료 처리로 회수하지 않습니다. 광고 중단/종료도 새 참여만 차단합니다.
- 확인이 필요한 지급은 **지급 확인·문의**에 표시됩니다. 원인을 해결한 뒤 같은 claim의 지급을 재시도합니다. 원인 해결 없이 새 코드를 발주하거나 지급 완료로 표시하지 않습니다.
- 쿠폰 발급사와의 사용 확인/취소/대체 발급 연동은 후속 범위입니다. 이 릴리스는 임의로 코드를 교체하거나 실제 사용을 확정하지 않습니다. 사용자의 “사용했어요”는 직접 기록으로 표시합니다.
- 지급된 코드는 소유자만 별도 요청으로 확인합니다. 목록·Q·통계·감사 로그에 코드를 넣지 않습니다. 화면 이동/숨김 시 코드를 지우고, 전체 API와 코드 응답에 no-store를 적용합니다.
- Chrome 브라우저 검증은 실제 플레이어와 실제 H.264 영상으로 수행했습니다. 실제 iPhone Safari/Android 기기와 각 광고주의 영상·쿠폰은 캠페인 공개 전 검수해야 합니다.
- 재생과 응답 검증은 시선이나 사람이 직접 보았다는 사실을 보증하지 않습니다. 카메라/시선 추적은 사용하지 않습니다.

## 운영 설정과 격리

- BRAND_EXCHANGE_ENABLED: 탐색 노출
- BRAND_EXCHANGE_STARTS_ENABLED: 신규 참여
- BRAND_EXCHANGE_Q_ENABLED: Q의 브랜드 추천
- BRAND_REWARD_ENCRYPTION_KEY: 전용 32바이트 AES-256-GCM 키(hex 64자). 다른 서비스 API 키를 암호화 키로 사용하지 않습니다.

배포 도구가 처음 한 번 서버에서 암호화 키를 생성하고 0600 .env 및 백업에 보존합니다. 이후 배포는 기존 키와 운영 플래그를 유지합니다. 플래그를 내려도 받은 혜택 조회·지급·문의 기능을 유지합니다. 암호화 키를 임의로 교체하지 마세요.

DavaQ 전용 DB에 0033 마이그레이션을 추가합니다. AnotherMe 소스·DB·컨테이너·공유 프록시는 변경하지 않습니다. 프로덕션 캠페인과 쿠폰은 시드하지 않습니다.

## 검증

- 격리 PostgreSQL 통합 검증: 77개 통과(기존 교환 28개 포함). 마지막 재고 경쟁, 예산 초과, 중복 요청·지급, 소유권, 위조 재생 위치, 단일 임대, 재도전 한도, 만료 회수, 캠페인 중단, 지급 오류 복구, 동의 철회·기억 삭제를 포함합니다.
- 암호화 무결성, 정답 시간/좌표, 레터박스·세로 영상, 잘못된 MP4 경계 단위 검증: 8개 통과.
- 실제 Chrome의 390×844 화면에서 영상 시작, 동시 재생, 두 정답, 일시정지, 이어하기, 성공까지 확인했습니다. 초기에 발견한 재생 시작 시 동기화 중단 문제를 수정했습니다.
- 통합 테스트는 고유 임시 스키마만 만들고 finally에서 정리합니다. 운영 테이블에 테스트 사용자를 추가하지 않습니다.
- 추가 빌드·CI·배포 결과는 별도 릴리스 기록으로 남깁니다.

## 후속 연결 자료

실제 캠페인을 시작하려면 광고주가 승인한 원본/수정본, 확정된 정답, 실제 쿠폰 재고와 사용·비용·문의 조건이 필요합니다. 공개 특허와 제공된 특허결정서만으로 최종 권리 범위를 단정하지 않았으며, 등록 명세서·최종 청구항에 따른 구성 확인은 별도 자료 수령 후 진행합니다.
